# کانتمو — وب‌سایت

پیاده‌سازی وب‌سایت کانتمو بر اساس اسناد ساختار صفحات (`HOME PAGE-Contemo.docx` و هفت فایل PDF).

## اجرا

```bash
npm run dev
```

سپس <http://localhost:3000>

```bash
npm run build && npm start
```

## استک

| لایه | انتخاب | چرا |
|---|---|---|
| فریم‌ورک | Next.js ۱۶ (App Router) | رندر سمت سرور برای سئو — بلاگ «فانوس» کانال اصلی جذب ارگانیک است |
| زبان | TypeScript | |
| استایل | Tailwind CSS ۴ با توکن‌های `@theme` | توکن‌ها مستقیم از سیستم طراحی می‌آیند |
| انیمیشن | Motion ۱۳ | همه انیمیشن‌ها به `prefers-reduced-motion` احترام می‌گذارند |
| فونت | Vazirmatn، Orbitron، JetBrains Mono | همه self-host؛ هیچ درخواستی به CDN خارجی نمی‌رود |

## تصمیم‌های مهم

**متن‌ها بدون دست‌زدن به کامپوننت‌ها قابل ویرایش‌اند.** همه‌چیز در `lib/content.ts` است.

**قیمت یک موتور دارد.** صفحه «برآورد هزینه» و فرم «ثبت پروژه» هر دو از `lib/pricing.ts` می‌خوانند، پس هرگز دو عدد متفاوت نشان نمی‌دهند.

**تولتیپ‌های منو روی موبایل هم کار می‌کنند.** سند خواسته بود برای فانوس، متین، اتاق فرمان و موفقیت با کانتمو تولتیپ طراحی شود. چون رویداد hover روی لمس وجود ندارد، همان متن در منوی موبایل به‌صورت دائمی زیر هر آیتم می‌آید و با `aria-describedby` برای صفحه‌خوان هم در دسترس است.

**جداسازی جهت.** شماره شبا، کد ملی، تلفن و ایمیل با `dir="ltr"` و `unicode-bidi: isolate` رندر می‌شوند تا ارقام در متن فارسی جابه‌جا نشوند.

**ارقام.** ارقام فارسی در متن روان، جداکننده هزارگان فارسی (٬) در اعداد فارسی، و `tabular-nums` هرجا عدد در ستون قرار می‌گیرد.

**گوشه قوس‌بریده.** امضای بصری سایت از کمان‌های لوگو گرفته شده، نه از پخ ۴۵ درجه. با ماسک CSS ساخته شده — بدون SVG و بدون ابعاد ثابت.

## تصویر هیرو

`public/img/star-trails.{webp,jpg}` — نوردهی ۸۰ دقیقه‌ای روی ستاره قطبی، عکس از **Adrian Mag** در Unsplash.
لایسنس Unsplash: استفاده تجاری آزاد، بدون نیاز به ذکر منبع (ذکرش اینجا صرفاً از سر ادب حرفه‌ای است).

انتخاب این عکس تزئینی نیست: رد دایره‌ای ستاره‌ها دور یک هسته‌ی روشن، همان هندسه‌ی لوگوی کانتموست.
تصویر در CSS خاکستری و سپس با `mix-blend-mode: color` روی `#2A38FF` رنگ‌آمیزی می‌شود تا دقیقاً روی
رنگ برند بنشیند — پس اگر رنگ برند عوض شود، عکس هم با آن عوض می‌شود.

WebP ۱۱۰ کیلوبایت با فالبک JPEG ۲۰۳ کیلوبایتی.

> تصاویر Pinterest و Dribbble عمداً استفاده نشده‌اند: آن‌ها اثر کپی‌رایت‌شده‌ی طراحان دیگرند و
> قرار دادنشان در یک سایت تجاری نقض حق مؤلف است.

## آنچه هنوز باقی است

- بک‌اند: ثبت پروژه، تیکت، ثبت‌نام و پرداخت همگی سمت کلاینت شبیه‌سازی شده‌اند
- احراز هویت و پنل کاربری (`/login` فعلاً صفحه نگه‌دارنده است)
- محتوای واقعی: نمونه‌کارها، نظرات کارفرماها با نام و برند واقعی، نوشته‌های فانوس
- اسناد حقوقی: `/terms` و `/privacy` باید پیش از فعال‌سازی ثبت‌نام کارپذیر نوشته شوند

## پنل ادمین فانوس

آدرس: `/admin` — برای افزودن، ویرایش و حذف مقاله‌های فانوس بدون دست‌زدن به کد.

**راه‌اندازی.** یک رمز در متغیر محیطی `ADMIN_PASSWORD` بگذارید (روی سیستم خودتان در `web/.env.local`،
روی سرور در تنظیمات محیط). بدون آن پنل غیرفعال است. اختیاری: `ADMIN_SECRET` (کلید امضای نشست) و
`POSTS_DATA_DIR` (مسیر ذخیره‌ی مقاله‌ها؛ پیش‌فرض `web/data`).

**کار با پنل.** «مقاله‌ی جدید» ← لینک گوگل‌داک را بگذارید و «ورود سند» را بزنید (سند باید برای «هر کسی که
لینک را دارد» قابل‌مشاهده باشد) ← فیلدها را مرور کنید ← «ذخیره و انتشار». بدون گوگل‌داک هم می‌توان متن را
دستی نوشت: `## تیتر`، `### زیرتیتر`، `- لیست`، `> نکته`، `**پررنگ**`. با تیک «پیش‌نویس» مقاله روی سایت دیده نمی‌شود.

**ذخیره‌سازی.** مقاله‌های اولیه در `lib/posts.ts` می‌مانند. مقاله‌های پنل در `data/posts.json` ذخیره می‌شوند و
بلافاصله روی سایت می‌آیند (`revalidatePath`). ویرایش یک مقاله‌ی اولیه نسخه‌ی جایگزین می‌سازد و «بازگشت به
اصلی» آن را برمی‌گرداند. این فایل باید روی **دیسک ماندگار** باشد: روی VPS یا Docker یک volume برای
`POSTS_DATA_DIR` بگذارید؛ روی هاست‌های serverless (مثل Vercel) کار نمی‌کند و باید ذخیره‌سازی به دیتابیس برود.
